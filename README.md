# ИИ-агент поиска работы на hh.ru

Каждое утро агент собирает свежие вакансии с hh.ru, отсеивает неподходящие, оценивает остальные через GigaChat по профилю кандидата и присылает в Telegram 5 лучших с кнопками «Интересно» / «Не надо». По вакансиям с «Интересно» готовит черновик сопроводительного письма. Откликается всегда человек — агент только находит, оценивает и готовит.

Сделал для собственного поиска работы. Проектировал, писал спецификацию, проверял и отлаживал сам; код писал вместе с Claude Code.

## Что получается на выходе

Сообщение в Telegram (пример):

```
⭐ 9/10 · Разработчик AI-решений / AI Automation Developer
Культура Гостеприимства · от 100 000 ₽ на руки
офис, гибрид, Киров · опыт 1–3 года

Подходит: разработка AI-решений, автоматизация, боты и внутренние
инструменты; коммерческий опыт не обязателен — важны свои проекты.
https://hh.ru/vacancy/…
              [ 👍 Интересно ]  [ 👎 Не надо ]
```

## Как устроено

Цепочка из 10 звеньев: одно звено — одно действие, выход каждого сохраняется в файл, поэтому любой шаг можно проверить и перезапустить отдельно. Нейросеть работает только в двух звеньях, всё остальное — обычный код.

| № | Звено | Что делает |
|---|---|---|
| 1 | Сбор | Страницы поиска hh по запросам из `config.json` (удалённо по России + свои регионы), пауза между запросами |
| 2 | Новизна | Убирает вакансии, виденные в прошлые дни |
| 3 | Фильтр | Правила без нейросети: стоп-слова в названии, опыт, регион, тема, давность |
| 4 | Подробности | Полный текст вакансии, навыки, адрес |
| 5 | Подвохи | Флаги: «доход в валюте», платное обучение, вилка ×10, оплата за смену |
| 6 | **Оценка (GigaChat)** | Балл 1–10 с объяснением, направление, подвохи — строго в JSON |
| 7 | Отбор | Порог ≥ 6, топ-5; перед отправкой проверяет, не ушла ли вакансия в архив |
| 8 | Доставка | Сообщения в Telegram с кнопками; нажатия забираются при следующем запуске — сервер не нужен |
| 9 | **Письмо (GigaChat)** | Сопроводительное письмо по вакансии с «Интересно» |
| 10 | Учёт | Таблица откликов (в работе) |

Подробно — в [spec.md](spec.md): назначение, правила фильтра, формат оценки, проверка качества.

## Как проверял качество

**Оценка вакансий.** Сам вслепую оценил 20 вакансий и сравнил с GigaChat. Сначала оценки совпадали (разница не больше 2 баллов) в 12 случаях из 20: модель завышала оценки техническим писателям, техподдержке и маркетингу «с ИИ». По расхождениям поправил инструкцию оценки и профиль — стало 18 из 20 (цель была 16).

**Фильтр.** В первых прогонах фильтр пропускал сотни нерелевантных вакансий: по слову «ИИ» hh находил, например, врачей, у которых ИИ упомянут в описании. Широкие запросы перевёл на поиск только по названию, добавил проверку темы и давности — в итоговом прогоне из 826 собранных вакансий на оценку ушло 153.

**Письма.** Первая версия писала письмо целиком — и GigaChat приписывал кандидату несуществующие проекты, даже при прямом запрете в инструкции и при проверке вторым запросом. Решение — изменить устройство, а не уговаривать модель: абзацы о проектах теперь заранее выверенные тексты (`letter_blocks.json`), модель только выбирает подходящие проекты и выписывает главную задачу из вакансии. Выдумать проект стало невозможно.

**Надёжность.** Повтор при сбоях сети и ответах сервера 429/5xx; проверка формата ответа модели с одним повторным запросом; повторный запуск звена докачивает только недостающее; подсчёт расхода токенов (оценка 153 вакансий — около 130 тыс. токенов).

## Технологии

Python 3.9 только со стандартной библиотекой (без сторонних пакетов), GigaChat API, Telegram Bot API, JSON, Git. Данные hh берутся из JSON, встроенного в страницу (`HH-Lux-InitialState`).

## Запуск

1. Скопировать `.env.example` в `.env` и вписать ключ GigaChat, токен Telegram-бота и номер чата.
2. Скачать корневой сертификат НУЦ Минцифры (на нём работают серверы GigaChat) в файл `russian_trusted_root_ca.pem` в папке проекта.
3. Скопировать `profile.example.md` в `profile.md` и описать себя.
4. Запустить:

```bash
python3 check_gigachat.py          # проверка связи с GigaChat
python3 -m agent.run all           # весь день целиком
python3 -m agent.run collect filter  # или отдельные звенья
```

Звенья по порядку: `inbox letters collect novelty filter details flags evaluate select deliver`. Выходы — в `data/runs/<дата>/`.

## Структура

```
agent/
  common.py    — загрузка страниц hh, пути, сохранение выходов звеньев
  links.py     — звенья 1–4: сбор, новизна, фильтр, подробности
  assess.py    — звенья 5–6: подвохи и оценка GigaChat
  digest.py    — звенья 7–8: отбор и отправка в Telegram
  letter.py    — звено 9: сопроводительное письмо
  gigachat.py  — клиент GigaChat (токен, запросы, повторы)
  telegram.py  — клиент Telegram Bot API (отправка, кнопки)
  run.py       — запуск звеньев
config.json        — запросы, регионы, стоп-слова, пороги
letter_blocks.json — выверенные абзацы о проектах для писем
spec.md            — спецификация
```
